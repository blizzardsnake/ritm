# RITM — бесплатный ИИ с телефона

В Android-версии: **Настройки → ИИ-тренер → Бесплатный ИИ на телефоне**. Этот вариант вызывает OpenRouter через интернет непосредственно с телефона; включённый ПК и собственный сервер не нужны.

1. Получите собственный ключ на [OpenRouter](https://openrouter.ai/keys). Регистрацию и ввод ключа выполняет владелец.
2. Проверьте [настройки приватности](https://openrouter.ai/settings/privacy). Запросы проходят через OpenRouter и провайдера выбранной модели.
3. Введите ключ в RITM, нажмите **Показать модели** и выберите **Автовыбор бесплатной модели** либо доступную модель с суффиксом `:free`.
4. Сохраните настройку. Перед анализом экран согласия покажет категории передаваемых данных; изменения программы требуют подтверждения.

Адрес сервиса заполнен автоматически. Ключ другого ранее настроенного провайдера в бесплатный режим не подставляется. Ключ остаётся вне истории, синхронизации и отчётов; на телефоне используется существующий механизм защищённого хранения. Реальная проверка хранения и запроса с ключом владельца ещё предстоит на телефоне.

RITM запрашивает свежий список моделей и показывает только объявленные бесплатные варианты с нулевыми ценами. Перед запросом проверяются адрес и название модели; запрос несёт ограничение `max_price` до нуля и фильтр `data_collection: deny`. Повтор запроса после отказа JSON-режима сохраняет эти ограничения. При отсутствии бесплатного подходящего провайдера запрос завершается ошибкой — приложение не подставляет платную модель.

По [текущему тарифу OpenRouter](https://openrouter.ai/pricing/) бесплатный уровень ограничен 50 запросами в день. Одна операция анализа может включать несколько запросов, например исправление ответа или повтор при перегрузке. Лимиты и доступность меняются; список проверяется при подключении. [Free Models Router](https://openrouter.ai/docs/guides/routing/routers/free-router) выбирает из доступных бесплатных моделей; [правила маршрутизации](https://openrouter.ai/docs/guides/routing/provider-selection) описывают ограничения цены и обработки данных. Проверено 2026-10-03.

Штатный ИИ-тренер анализирует программу, тренировочные записи, вес тела и ответы владельца. Общий «Недельный разбор» уже объединяет питание, тренировки и доступные данные восстановления: по отдельному согласию отправляет отчёт, принимает проверяемые предложения и показывает будущую тренировку до применения. Вы выбираете изменения; журнал позволяет отменить их с проверкой конфликтов. Подробности — `personal-weekly-review.md`. Никакие личные записи в OpenRouter при разработке не отправлялись; реальный ответ с ключом владельца ещё нужно проверить на телефоне.

Проверки: фильтрация каталога, запрет платных моделей и другого адреса до сетевого вызова, отказ без ключа, сохранение нулевой цены при повторе, отказ повреждённых настроек, обычные совместимые провайдеры, экран подключения/согласия, отдельный ключ для OpenRouter. Реальные возможности Mi Fitness и запрос с ключом владельца входят в приёмку на телефоне.
