# RITM — цели и достижения

Откройте **Статистика → Цели, которые выбираешь ты → Изменить**. Обычные поля задают тренировки в неделю, шаги за день, количество полностью записанных дней питания, вес тела и КБЖУ. Пустое поле снимает цель. Целевой вес и КБЖУ используют те же настройки, что исходный график веса и дневник питания.

Недельное сравнение показывает количество наблюдавшихся дней отдельно для каждой величины. Среднее КБЖУ рассчитано только по дням, которые владелец отметил полными и у которых известны все четыре показателя. Шаги берутся из выбранных источников. Интервал сна без полного покрытия стадиями не считается подтверждённым временем сна. Пропуски остаются прочерками; реальные нулевые шаги сохраняются.

Штатные графики openGym, оценка 1RM, карта **Баланс мышц → Неделя**, усталость и сила сохранены. Недельный план следует выбранному началу недели, датированным переносам и дням отдыха. В объединённой тренировке пропущенная программа не засчитывается только на основании её ID: требуется выполненный рабочий подход с принадлежностью к этой программе. Старые одиночные тренировки поддерживаются; для старой объединённой тренировки без принадлежности подходов полнота плана не предполагается.

Восемь достижений: первая, 10, 25 и 50 тренировок; полная неделя текущего расписания; первый рекорд 1RM относительно предыдущего подходящего результата; семь полных дней питания; семь измеренных дней выполнения собственной цели шагов. Семь дней могут быть с перерывами. Рекорд исключает разминку, упражнения с помощью и записи вне прогрессии. Дубли с одинаковым ID считаются один раз. В старой истории расписание на момент каждой тренировки неизвестно, поэтому достижение недели явно использует текущее расписание.

Журнал наград сохраняется при открытии статистики и перед экспортом/резервным копированием. Исправление или удаление записи пересчитывает условия, сохраняя дату первой выдачи. Импорт старой истории не вызывает уведомления по каждой награде. Статистика и общий отчёт вызывают один калькулятор; отчёт содержит условия, прогресс, подтверждающие записи и версию правил.

Проверено: границы наград, два занятия в день, переносы/отдых/объединённые занятия, исключение разминки и неподходящих рекордов, неполное питание, неизвестные шаги, повторный импорт, отзыв квалификации, нормальные поля редактирования, согласованность экспорта и сохранение исходной карты мышц. Проверены ширины 393, 856, 1000 и 1266 px: меню по центру, горизонтального переполнения нет. Проверка настоящего телефона входит в финальную приёмку APK.
