# История и экспорт openGym Personal

Экспорт позволяет передать полную историю для анализа и восстановить личный профиль. Читаемый отчёт использует те же расчёты, что экраны приложения.

## Запись событий

Существующие тренировки сохраняют начало, завершение, локальную дату, упражнения, целевые и выполненные подходы, веса, повторения, усилие RPE или RIR при наличии, заметки и рекорды. Добавляется явное указание часового пояса для новых событий. Завершение подхода получает время записи; для старых тренировок оно остаётся неизвестным и не восстанавливается догадкой. Редактирование прошлой тренировки сохраняет время первоначальной записи и время изменения.

Еда содержит время приёма и снимок продукта. Измерения часов содержат интервал, источник, время получения и признаки качества. Показатели тела сохраняют существующую историю измерений. Владелец может задать дату начала наблюдений; отчёт показывает фактический объём имеющейся истории.

## Форматы выгрузки

Настройки предлагают «Полная копия» и «Отчёт для анализа». Полная копия сохраняет все исходные разделы состояния и добавленные данные. Фотографии и видео можно включить через существующий ZIP экспорт. Импорт старой JSON копии и новой копии остаётся доступным.

Отчёт для анализа — JSON конверт с `format: opengym-personal-analysis`, `formatVersion`, `generatedAt`, ID профиля, выбранным интервалом, часовым поясом, единицами, историей и сводками. Он содержит план будущих занятий, фактически выполненные тренировки, питание, вес тела, показатели часов, цели и историю принятых изменений. Секреты ИИ, токены сопряжения и данные входа в него не включаются.

Дополнительно создаётся читаемый Markdown отчёт: тренировки и динамика нагрузок, КБЖУ по дням, полнота рациона, изменение веса тела, доступные сон и активность, пробелы данных и текущая программа. Для выбранной недели передаются также предыдущие четыре недели контекста, если они существуют. Полный диапазон истории можно выгрузить отдельно.

## Полнота и происхождение

Каждая сводка указывает период и исходные единицы. Пустая неделя, неполный рацион, отсутствие измерений сна и устаревшая синхронизация отмечаются явно. Суммарный расход энергии часов не складывается с активным расходом и тренировкой второй раз. Импортированные занятия часов отделяются от вручную записанных силовых занятий; возможное совпадение показывается как связь двух записей, без создания второй силовой тренировки.

Экспорт формируется из согласованного сохранённого снимка. В интерфейсе видны время формирования и последняя синхронизация часов. Передача идёт через штатное меню «Поделиться» или файл в выбранной папке обмена. Ошибка записи файла не удаляет профиль или предыдущую исправную копию.

## Проверки

Проверяются перенос резервной копии 1.3.9, полный цикл экспорт и импорт новой версии, сохранение новых полей при синхронизации, два занятия за один день, переход через полночь, часовые пояса, RPE/RIR, разминка и рабочие подходы, дробные веса и неполные данные. Числа JSON, читаемого отчёта и экранов совпадают для одного снимка. Отдельно проверяется отсутствие секретов.
