# Бесплатные продукты и КБЖУ

APK содержит 63 продукта с русскими названиями из официального USDA FoodData Central SR Legacy, выпуск 2018-04. Это справочные значения конкретных записей: например, зернёный cottage cheese не заменяет этикетку российского творога. Сырой вес и масса после приготовления выбираются отдельно. Готовый к употреблению продукт имеет состояние `ready`, отдельно от этикетки `label`.

Источник: [официальные выгрузки USDA](https://fdc.nal.usda.gov/download-datasets/), файл `FoodData_Central_sr_legacy_food_json_2018-04.zip`. Исходный JSON SHA256: `70d4235ae3a2bdf48a7b9eaa1286a83fa67b6f3270436c9ce8b008213f500129`. Данные USDA — public domain / CC0; каждый элемент сохраняет FDC ID, исходное название, версию набора и ссылку.

Для воспроизведения скачайте и распакуйте официальный файл, затем выполните из корня исходников:

```text
node scripts/build-food-catalogue.mjs <путь к распакованному USDA JSON>
```

Список выбранных записей находится в `scripts/food-catalogue-selection.json`. Генератор берёт Protein (1003), Total lipid (1004), Carbohydrate by difference (1005) и Energy kcal (1008), с fallback Energy kJ (1062) / 4.184. Пропуски остаются неизвестными. Масса продуктов — граммы съедобной части, не масса упаковки/кости.

Для упакованных продуктов используется [Open Food Facts](https://openfoodfacts.github.io/openfoodfacts-server/api/): чтение v3.6, текстовый поиск через поддерживаемый `cgi/search.pl`. Запросы запускаются кнопкой. Ограничения клиента: 10 поисков и 15 запросов штрихкода за скользящую минуту, с учётом Retry-After; повторных автоматических запросов нет. Сохранённые результаты доступны без сети.

Контактный e-mail задаётся владельцем один раз: официальный API требует `AppName/Version (ContactEmail)` в User-Agent. Android использует нативный HTTP для этого заголовка. Сервис получает строку поиска или штрихкод и идентификатор клиента; личный дневник, тренировки и данные часов туда не отправляются. Записи OFF сохраняют происхождение и обозначение ODbL / Database Contents License. Изображения продуктов в справочник не включаются.

Этикетка на 100 мл требует плотности для перевода в граммы. Без плотности значения КБЖУ неизвестны; 100 мл не считается автоматически 100 г. Карточки на порцию не подменяют значения на 100 г. Для ручного ввода можно использовать собственную этикетку.
